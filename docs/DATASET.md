# Nexora Enterprise Knowledge Base

This package contains the fictional enterprise knowledge base used with the Staff AI Engineer agent assignment.

The content is organized into:

- company — company overview and canonical entity identifiers
- teams — ownership, responsibilities, and team context
- services — service capabilities, ownership, dependencies, and reliability notes
- products — product capabilities and service relationships
- projects — project scope, ownership, dependencies, and success criteria
- customers — products, important services, operational context, and related incidents
- incidents — incident summaries, impact, root cause, resolution, and follow-up work
- runbooks — operational response procedures
- policies — production access, incident management, and customer-data controls
- architecture — platform, payment, identity, and observability architecture
- security — security review guidance and a document containing adversarial retrieved content for agent-safety testing

The dataset is intentionally cross-linked so that questions can require multiple documents and multiple hops across entities.

All entities are fictional. Dates and operational metrics are illustrative.
