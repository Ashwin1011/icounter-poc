# Policy — Customer Data Handling

Customer profile information and communication preferences must be handled as controlled customer data.

### Requirements
- Services should access only the attributes they need.
- Raw payment card numbers must not be stored by application services.
- Customer-data exports require approved authorization.
- Logs must avoid exposing sensitive customer attributes.
- Third-party processing must use approved contracts and security controls.

Security Engineering reviews systems that introduce new customer-data flows.
