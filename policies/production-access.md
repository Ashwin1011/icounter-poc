# Policy — Production Access

Production access must be granted through approved identity controls and time-bounded mechanisms.

### Requirements
- Users must authenticate through Identity Service.
- Privileged access should use approved elevated-access workflows.
- Access should be limited to the minimum required scope.
- Emergency access must be documented after the fact with the reason, duration, and systems accessed.
- Service credentials must not be copied into source code or shared through chat.

Security Engineering owns this policy. SRE operates the standard production access workflow.
