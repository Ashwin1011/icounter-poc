# PROD-BILL — BillingPro

BillingPro manages subscriptions, invoices, payment collection, and revenue reporting.

### Core services
- API Gateway
- Identity Service
- Payment Service
- Data Platform

BluePeak Travel (CUST-BLUEPEAK) uses BillingPro for subscription billing.

Payment Service authorization is a critical dependency for payment collection workflows. Billing reporting depends on the freshness of Data Platform datasets.
