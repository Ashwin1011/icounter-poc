# PROD-COM — CommerceCloud

CommerceCloud provides product catalog, checkout, order management, and customer-facing commerce capabilities.

### Core services
- API Gateway
- Identity Service
- Order Service
- Payment Service
- Customer Profile Service
- Notification Service
- Search Service

CommerceCloud depends on Payment Service during checkout and Order Service for order lifecycle management.

Major customers using CommerceCloud include Northstar Retail (CUST-NORTHSTAR) and Redwood Outfitters (CUST-REDWOOD).
