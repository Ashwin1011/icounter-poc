# PROD-SUP — SupportHub

SupportHub provides support-agent workflows, customer ticketing, internal notifications, and searchable knowledge.

### Core services
- API Gateway
- Identity Service
- Customer Profile Service
- Notification Service
- Search Service

GreenLeaf Health (CUST-GREENLEAF) uses SupportHub.

SupportHub authentication depends on Identity Service. Search freshness depends on Search Service indexing.
