# PROJ-ATLAS — Project Atlas

Project Atlas standardizes observability across customer-facing services.

**Technical owner:** Sofia Alvarez
**Primary team:** Core Platform (TEAM-PLAT)
**Status:** In progress

### Scope
- Standardize correlation IDs
- Standardize service-level metrics
- Improve distributed tracing
- Create common service dashboards

### Services involved
API Gateway, Search Service, Payment Service, Order Service, Notification Service, Customer Profile Service.

SRE (TEAM-SRE) is a major stakeholder and reviews reliability dashboards created by Atlas.
