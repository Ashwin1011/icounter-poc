# TEAM-ID — Identity Platform

Identity Platform owns the Identity Service (SVC-ID), including login, session management, OAuth client registration, and service-to-service identity primitives.

**Manager:** Priya Nair
**Technical Lead:** Daniel Ortiz
**Primary on-call rotation:** IDENTITY-PRIMARY

Identity Service is a dependency for API Gateway, Payment Service, Order Service, and SupportHub authentication flows.

The team owns Project Orion (PROJ-ORION), which focuses on migrating legacy OAuth clients to the new identity platform.
